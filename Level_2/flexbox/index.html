Main Content

This page is the Level 2 layout from the activity: a header, a navigation bar, a main content area (70%) with a sidebar (30%), and a footer. It is built twice with identical HTML and identical colors and type. Only the layout CSS file changes.

How it responds

  • Desktop, 768px and wider: the main content and the sidebar sit side by side at 70% and 30%.
  • Mobile, under 768px: every section stacks vertically in a single column.

Resize the browser window, or open the developer tools device toolbar, to watch the layout change at the breakpoint. Open the other version in a second tab and compare: the two should look the same at every width.
